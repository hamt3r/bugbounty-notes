# 2FA Enablement Before Email Verification

## Summary
Ability to enable Two-Factor Authentication on an account with an unverified email address.

## Steps
1. Create a new GitHub account
2. Do not verify the email address
3. Navigate to security settings
4. Enable 2FA successfully

## Expected Behavior
Email verification should be required before enabling security-sensitive features.

## Impact
- Inconsistent authentication state
- Potential account recovery and abuse risks
